# VoxBridge Unity Tools

**Two C# scripts to enhance your Unity workflow.**

---

## Installation

**Copy both `.cs` files to your Unity project's `Assets/Editor/` folder**  
Unity will compile them automatically.

---

## 1. UnityLODGenerator.cs
**Creates LOD prefabs for mobile optimization**

**How to use:**
1. Import your VoxBridge model into Unity
2. Select the model in Project window  
3. Right-click → VoxBridge → Generate LOD Prefab
4. Done! LOD prefab created with 3 quality levels

---

## 2. VoxbridgeImport.cs
**Automatic import configuration**

**How to use:**
- Just import your VoxBridge ZIP into Unity
- This script automatically configures animations and materials
- No manual setup needed!
